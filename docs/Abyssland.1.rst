NAME
====

Abyssland - Dynamic tiling Wayland compositor

SYNOPSIS
========

**Abyssland** [*arg [...]*].

DESCRIPTION
===========

**Abyssland** is an independent, highly customizable, 
dynamic tiling Wayland compositor that doesn't sacrifice on its looks. 

You can launch Abyssland by either going into a TTY and
executing **Abyssland**, or with a login manager.

NOTICE
======

Abyssland is still in pretty early development compared to some other Wayland compositors.

Although Abyssland is pretty stable, it may have some bugs.

CONFIGURATION
=============

For configuration information please see <*https://github.com/AbyssWM/Abyssland/wiki*>.

OPTIONS
=======

**-h**, **--help**
    Show command usage.

**-c**, **--config**
    Specify config file to use.

**--socket**
    Sets the Wayland socket name (for Wayland socket handover)

**--wayland-fd**
    Sets the Wayland socket file descriptor (for Wayland socket handover)
